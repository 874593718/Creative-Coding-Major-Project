# 四季 User Input：运行、演示与代码解释

## 先运行

解压完整项目，保留 libraries 文件夹，用浏览器打开 index.html。也可以通过 VS Code Live Server 或其他本地静态服务器打开。程序不需要 npm，不依赖在线 p5 CDN。

先点击 Auto: On，将它变成 Auto: Off，再用底部四季按钮逐项演示。原有四季切换和自然漂动均保留，切换后需要短暂等待原有季节过渡。

## 四季操作

| 季节 | 操作 | 结果 |
| --- | --- | --- |
| 春 | 鼠标靠近荷叶，点击带花的荷叶 | 局部高亮；该花展开，再点闭合；途中再点可反向 |
| 夏 | 按住一片荷叶，拖到池塘内其他位置后松开 | 花与叶一起移动，沿途产生水波；留在新位置继续自然漂动 |
| 夏 | 不拖动，只点击带花的荷叶 | 仍可单独开合，不会把拖动误当点击 |
| 秋 | 按住鼠标，缓慢穿过附近落叶；稍停，再拖动并松开 | 最多聚拢 25 片原有落叶；松开后留在水面形成一簇 |
| 冬 | 按住并拖动鼠标经过雪花，稍停后松开 | 附近雪花收拢，松手后散开并继续下落；拖动留下短暂雪迹 |
| 所有季节 | 点击没有花的水面 | 水波扩散，附近荷叶产生短暂偏移 |
| 键盘 B / b | 全开 | 所有花朵目标设为展开；秋冬由原有季节模块隐藏花朵，所以不会强制长出花 |
| 键盘 R / r | 重置你的变化 | 花朵逐渐闭合；荷叶回到初始基础位置；清除水波、落叶簇、雪迹和当前抓取 |

Hover 时附近荷叶会轻微让开，离开后回位。页顶标题和页底按钮区预留给界面，不触发画布操作。冬天没有荷叶是队友原有季节效果，不是拖动失效。

秋冬只收集鼠标附近实际经过的对象，空白处按住不会凭空制造落叶或雪。移动慢一点、在有对象的位置稍停，效果更清楚。

## 你负责的代码在哪里

主要实现位于 input-controls.js。为了接入现有绘制与更新，有四个文件含少量标注 USER INPUT 的适配修改：

| 文件 | 修改 |
| --- | --- |
| sketch.js | 新增唯一的 mouseReleased 入口，转发给 handleInputReleased |
| perlin-lilies.js | 在原有位置更新处叠加输入/水波偏移；拖动时跟随基础位置；绘花时接入独立开合状态 |
| time-mechanic.js | 在原有粒子更新循环中调用 applyInputToParticle，应用聚拢与释放 |
| index.html | 补上四季互动和键盘操作说明 |

audio-mechanic.js 保持原样。没有替队友制作音频或重新设计季节时序。不能只替换 input-controls.js：缺少这些适配行，已有绘制函数不会显示你的变化。

## 一条完整的操作链

**用户按下 → 记录状态 → draw 更新 → 模块显示反馈 → 用户松开 → 保存或释放。**

1. 主文件的 mousePressed 调用 handleInputPressed，记录按下位置、当前季节及被选中的荷叶。
2. updateInputMechanic 每帧读取 mouseX / mouseY。它只在已经按下时执行拖动和收集。
3. 鼠标从按下位置移动超过 6 像素，moved 变成 true。这样松手时不会把拖动当成点击开花。
4. mouseReleased 调用 handleInputReleased：短点击开合花；夏天松手保留基础位置；秋天松手留下叶簇；冬天松手释放雪花。

## 每个功能如何用基础代码实现

**花朵开合：** 每朵花保存 inputBloom（当前值 0–30）和 inputTarget（目标 0 或 30）。inputStep 用 if 判断大小，每帧加减 0.5。drawInputLilyFlower 用这个比例调整原有椭圆花瓣的排列角度。完全展开时调用组员原本的 drawLilyFlower。没有逐片三维模拟。

**Hover 与让开：** inputFindLily 使用椭圆判断找到鼠标下面的荷叶。inputHover 控制轮廓出现；inputPushX/Y 保存额外偏移。鼠标离开后，偏移用固定步长回到 0。小荷叶的偏移更小，避免一直躲开导致点不中。

**夏天拖动：** dragIndex 保存选中的数组索引；grabX/Y 保存抓取点偏移。拖动改变 baseX/Y，松开后不重置。噪声继续围绕新基础位置漂动。R 可以回到最初布局。当前没有新增防重叠算法，因此手动拖动可能让荷叶重叠。

**水波：** pond.ripples 是共享数组。每个对象保存 x/y、radius、strength、age。半径增加、强度减少，90 帧后移除；最多 12 个。getInputLilyOffset 根据水波与荷叶的距离，返回小幅偏移。最终位置仍由 Perlin 的同一个函数写入，避免两个模块先后覆盖位置。

**秋天聚叶：** held 数组保存原有 particles 中被选中的对象引用，不复制出另一套空中落叶。applyInputToParticle 在时间模块内让选中对象逐步跟随鼠标。松开时把当前位置存成 inputLeaves，原空中粒子回到上方复用；水面落叶最多 40 片。

**冬天拨雪：** 同样收集原有对象。松开设置 inputRelease，之后用简单坐标加减短暂向两侧散开，再继续原有下落。inputSnow 记录拖动位置；雪迹用小椭圆显示，75 帧后移除，最多 40 个。

**松散排列：** 被抓取的落叶与雪花用课堂 sin/cos 摆成小团，避免全部重叠在一个点。它是确定的坐标排列，不是 noise、随机或物理模拟。

## 全局、对象属性、局部变量

| 类型 | 例子 | 用途 |
| --- | --- | --- |
| 全局 | inputHand、inputLeaves、inputSnow | 跨帧保存操作和效果 |
| 对象属性 | lily.inputBloom、lily.inputTarget、particle.inputHeld | 每个对象各自的状态 |
| 局部 | dx、dy、distance、target、循环 i | 函数内部一次计算 |
| 参数 | state、x、y、pressedKey | 主文件传入共享状态和输入 |

本版顺应团队已有的函数与对象结构，没有强行为课程展示额外添加类。后续若团队需要，也可以再按 Week 7 的类组织；当前功能不依赖复杂继承。

## 缩放、切季和性能

位置使用 0–1 相对坐标，绘制和距离检测时乘画布尺寸。窗口改变不会重建荷叶，因此拖动结果和开合状态会保留。

切换季节时取消旧的抓取，并清掉落叶簇和雪迹，避免秋叶突然变成一团雪。开合目标和夏天改变的荷叶基础位置保留到 R 重置。

数量上限：抓取 25；水波 12；水面落叶 40；雪迹 40。过期对象通过普通循环筛选到保留数组，不用 splice / filter / map。

动画按帧更新，设备帧率低时会变慢。此版本没有引入未经核对的 deltaTime 或复杂物理。触屏交互尚未专门验证，当前以鼠标和键盘演示为主。

## 明天演示顺序

1. Auto 关闭，Spring：Hover 一片带花荷叶，点击开花，再点反向。
2. Summer：B 全开，按住一片荷叶拖走，松手展示停留与漂动。
3. 点击空白水面，看水波经过附近荷叶。
4. Autumn：在落叶经过处按住、拖动、松手，展示留下的叶簇。
5. Winter：收拢雪花，拖动留痕，再松开散落。
6. R 重置，再打开 Auto，展示原有四季功能仍在。
